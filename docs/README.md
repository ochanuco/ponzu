# Ponzu Documentation

Ponzu is a local-first voice assistant designed to run primarily on Apple Silicon.

This archive contains the current project decisions and initial design documents.

## Files

- `ADR.md` — Architecture Decision Records
- `ROADMAP.md` — Development roadmap
- `DESIGN.md` — Initial system design
- `SECURITY.md` — Public repository and secrets handling policy

## Current MVP Scope

1. Wake word detection
2. Speech-to-text
3. Local LLM inference
4. Text-to-speech via VOICEVOX
5. Audio playback
6. Return to idle state

Discord and external cloud APIs are intentionally excluded from the MVP.
